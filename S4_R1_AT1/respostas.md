# Perguntas & Respostas

## EXERCÍCIOS DE APROPRIAÇÃO

**Explique o que é uma interface:**

É um contrato que define quais métodos uma classe deve possuir. Ela estabelece um padrão que as classes tem que seguir, mas não define como esses métodos devem funcionar.

**Qual a diferença entre classe abstrata e interface?**

A classe abstrata pode ter atributos, métodos prontos e métodos que as classes filhas precisam implementar.
A interface define os métodos obrigatórios que as classes devem implementar, funcionando como um contrato.

**Por que interfaces ajudam no trabalho em equipe?**

Porque com elas todos os desenvolvedores seguem o mesmo padrão de código, o que ajuda a deixar tudo mais organizado.

## DESAFIO PROFISSIONAL
Um novo desenvolvedor entrou no projeto.

**Como interfaces ajudam ele a entender o sistema mais rápido?**

Porque a interface mostra quais métodos são obrigatórios em cada classe para que o novo desenvolvedor consiga entender melhor como o sistema funciona e saber quais padrões ele tem que seguir.

**O que acontece se ele não seguir o contrato?**

O PHP mostra um erro se uma classe que utiliza uma interface não possuir todos os métodos exigidos por ela. Isso evita que as classes fiquem incompletas.
